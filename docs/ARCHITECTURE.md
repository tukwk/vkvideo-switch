# Архитектура

## Слои

```
+-----------------------------------------------------+
| UI                       src/ui.c                   |
|  - framebuffer 1280x720, DejaVu Sans (stb_truetype) |
|  - карточки 3x2, обложки, чипы категорий            |
+-----------------------------------------------------+
| Сценарии                src/main.c                  |
|  - ввод (геймпад/swkbd), пагинация, запуск плеера   |
+-----------------------------------------------------+
| VK                      src/feed.c, src/vk.c        |
|  - video.search / video.getCatalog -> лента         |
|  - video.get -> прямые ссылки, качество             |
+-----------------------------------------------------+
| Транспорт               src/net.c, src/http.c       |
|  - mbedTLS + сокеты libnx                           |
|  - API: GET в память, картинки: GET в память        |
+-----------------------------------------------------+
| Стрим                   src/stream.c                |
|  - HTTPS + Range в кольцевой буфер 48 МБ            |
|  - фоновый поток, backpressure, реконнект           |
+-----------------------------------------------------+
| Плеер                   src/player.c                |
|  - ffmpeg: MP4/H.264/AAC (software)                 |
|  - swscale -> RGBA -> framebuffer                   |
|  - swresample -> S16 48k -> audout                  |
|  - seek, часы по аудио, watchdog                    |
+-----------------------------------------------------+
| Платформа               libnx / Horizon OS          |
+-----------------------------------------------------+
```

`src/vk.c` и `src/feed.c` не зависят от Switch и покрыты хостовыми тестами
(`tools/test-host.sh`).

## Лента

- Категории — фиксированный список запросов (`музыка`, `игры`, ...).
- «Рекомендации» → `video.getCatalog` (внутренний метод VK). Ответ заранее
  неизвестен, поэтому используется **глубокий обход JSON**: любой объект с
  `id` + `owner_id` + `title` считается видео. Если метод не отвечает —
  fallback на `video.search?q=тренды`.
- `video.search`: `q`, `count=24`, `offset`, `extended=1`, `sort=2`.
- Обложка выбирается из `image[]`/`first_frame[]`: приоритет — 320..640 px,
  без `with_padding`; протокол-относительные URL (`//...`) получают `https:`.
- Дедупликация по `(owner_id, id)`, максимум 60 карточек, пагинация по 24.

## UI

- Один framebuffer RGBA8888 1280×720, двойная буферизация.
- Перерисовка только по событию (dirty): ввод, загрузка ленты/обложки.
- Текст: stb_truetype + DejaVu Sans из `data/font.bin` (bin2o), полная
  поддержка кириллицы. Глифы растеризуются на лету (без кэша — объёмы малые).
- Обложки: stb_image (JPEG/PNG) → aspect-fill в 384×216 → LRU-кэш на 24
  карточки (~8 МБ). Неудачные загрузки кэшируются как «failed», чтобы не
  долбить сеть бесконечно.
- Перед swkbd и плеером framebuffer закрывается (`ui_suspend`), после —
  создаётся заново (`ui_resume`).

## VK API

`video.get` (v=5.199):

```
GET https://api.vk.com/method/video.get
    ?v=5.199&videos=<owner_id>_<video_id>&access_token=<token>
```

`files.mp4_240..1080` — подписанные временные ссылки; `hls` и `external` пока
не поддерживаются (плеер — только прогрессивный MP4). Ссылки обновляются
перед каждым воспроизведением.

## Сеть и стрим

- `net.c` — HTTPS GET для API, TLS 1.2/1.3, SNI, ответ в буфер.
  Проверка сертификата пока отключена (`MBEDTLS_SSL_VERIFY_NONE`).
- `http.c` — HTTP-клиент: `HTTP/1.0`, до 5 редиректов,
  `http_get_mem` для картинок (лимит 3 МБ).
- `stream.c` — прогрессивный стрим видео:
  - фоновый поток качает `Range`-запросами в кольцевой буфер 48 МБ;
  - освобождение прочитанного — O(1), без `memmove`;
  - backpressure: поток ждёт читателя при переполнении;
  - ранний обрыв CDN → реконнект с текущего байта;
  - `stream_seek` не рвёт соединение, если цель чуть впереди скачанного
    края (ждёт докачку);
  - короткий неблокирующий режим, чтобы плеер успевал рендерить кадры.
- Энтропия — `csrng`, время — системное.

## Плеер

1. `avformat_open_input` через кастомный AVIO поверх `stream.c`.
2. H.264 и AAC декодеры; H.264 в 4 frame-thread'а (software).
3. Декодирование ограничено: пакет придерживается, пока очередь кадров
   не опустится до 6 — без «убегания» декодера и дыр в PTS.
4. Видео: `sws_getCachedContext` → RGBA 1280×720 с letterbox.
5. Звук: `swresample` → S16 48 кГц stereo, 6 буферов → `audout`.
6. Часы: `audoutGetAudioOutPlayedSampleCount`; если звук на мгновение
   встал, видео продолжает по системному времени.
7. Seek: `av_seek_frame(BACKWARD)` + обрезка аудио и видео по целевой
   позиции, очистка очереди, flush декодеров.
8. Watchdog: 6 секунд без картинки → перезапуск конвейера с текущей позиции.
9. История и позиция сохраняются в `/switch/vkvideo/`.
10. На время просмотра отключается автосон; при уходе в фон — пауза.

Ограничения: только прогрессивный MP4; HLS, лайвы и NVDEC не используются.
