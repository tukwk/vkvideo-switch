# Roadmap

## v0.1 — каркас (сделано)

- [x] Разбор ссылок VK Видео, `video.get`, JSON.
- [x] HTTPS на mbedTLS, конфиг на SD.
- [x] Хостовые тесты ядра.

## v0.2 — воспроизведение (сделано)

- [x] Скачивание потока на SD с прогрессом.
- [x] ffmpeg: MP4/H.264/AAC, framebuffer + audout.
- [x] A/V-синхронизация, кэш скачанного.
- [x] Ввод токена через swkbd.

## v0.3 — визуальный клиент (сделано)

- [x] Framebuffer UI: сетка карточек 3×2, обложки, шрифт DejaVu Sans.
- [x] Категории (`video.search`) и «Рекомендации» (`video.getCatalog`).
- [x] Поиск через swkbd.
- [x] Пагинация, LRU-кэш обложек, отрицательный кэш ошибок.
- [x] Хостовые тесты парсера ленты.

## v0.4 — стриминг и удобство (сделано)

- [x] Прогрессивный HTTPS-стриминг (кольцевой буфер, `Range`).
- [x] Пауза (`A` в плеере) и seek ±10 / ±60 с.
- [x] Оверлей с временем/позицией и громкостью.
- [x] «Продолжить просмотр» и история на SD.
- [x] Переключение качества кнопкой `-`.
- [x] Ручная/per-file синхронизация после seek, watchdog от зависаний.

## v0.4.1 — безопасность и стабильность (сделано)

- [x] Проверка TLS-сертификатов: CA-бандл Mozilla, `VERIFY_REQUIRED`.
- [x] IPv4-коннект API с таймаутом и ретраями (после сна).
- [x] Сон/пробуждение: пауза вместо выхода, переподключение потока.
- [x] После seek часы и звук ждут, пока декодер дойдёт до цели.

## v0.5 — производительность и надёжность

- [ ] NVDEC (`h264_nvtegra`) для 720/1080p, если стабилен на контенте VK.
- [ ] HLS: плейлисты, лайвы, адаптивное качество.
- [ ] CA-bundle + `VERIFY_REQUIRED`.
- [ ] Параллельная докачка несколькими соединениями.

## v0.6 — полировка

- [ ] Иконка/NACP, анимации выбора.
- [ ] Субтитры (если отдаёт VK).
- [ ] CI: сборка NRO + хостовые тесты.

## Вне рамок

- Widevine/DRM-контент.
- Скачивание видео в обход правил VK.
- Обход региональных ограничений.
